Prefer the extension.

DevTools device emulation is per tab, so links opened in new windows load as desktop. The chunky capture extension steps the one emulated tab through this list instead. Unzip it, load it from chrome://extensions (Developer mode → Load unpacked), and enable "Allow in Incognito".

Session checklist
  1. Close every incognito window, then open a new one.
  2. Open chrome://net-export, tick "Include raw bytes", and start logging.
  3. For each link below (or for the extension's tab), turn on the DevTools device toolbar with Pixel 10.
  4. Load the pages in order: Google first, then Etsy. Stop at any "unusual traffic", CAPTCHA or block page.
  5. Stop logging and save as data/netlogs/capture-YYYY-MM-DD.json.
